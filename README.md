# LPU Library Seat and Resource Booking System

A student-developed front-end demonstration project for **Lovely Professional University (LPU), Phagwara, Punjab, India**, created for the *Internet Programming* course.

**Tagline:** Your Space to Learn, Research and Grow

## Important disclaimer
This is **not** an official LPU website and **not** a live booking service. No real data is sent, stored or checked. The seat layout, zones and service names are sample content for demonstration. The project contains no official phone numbers, email addresses, policies, seat counts or operating hours. For real library information, contact the LPU Library directly.

## Files
| File | Purpose |
|------|---------|
| `index.html` | All page structure and a small inline vanilla JavaScript block |
| `style.css` | All styling and responsive rules |
| `README.md` | This documentation |

## How to run
1. Unzip the archive.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in any modern browser. No server or installation is needed.

## Features
- LPU-branded header, welcome section and footer
- Responsive layout (desktop, tablet, mobile) with a CSS-only mobile menu
- Booking form with validation and an on-screen booking summary
- Clickable sample seat map
- Accessible markup: skip link, labelled fields, focus styles, reduced-motion support

## HTML5 and CSS3 concepts demonstrated
Semantic elements (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`), form controls and input types (`date`, `time`, `select`, `textarea`), `fieldset`/`legend`, CSS variables, Flexbox, Grid, media queries, pseudo-classes and pseudo-elements, counters, transitions, `clamp()` and sticky positioning.

## About the logo
No LPU logo image was supplied with the request, so the header uses a plain text-based "LPU" identifier. To use the official logo, embed it in `index.html` as a Base64 data URI in place of the `.mark` element, keeping its original proportions. Only use it if you are permitted to.
